# Desafio Power BI Analyst – DIO

## Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio prático da formação Power BI Analyst da Digital Innovation One (DIO).

O objetivo é desenvolver habilidades na criação de relatórios interativos, análise de dados e construção de visualizações utilizando o Microsoft Power BI.

A partir da base de dados Financial Sample, foi desenvolvido um relatório com três páginas, permitindo analisar o faturamento, o lucro, as unidades vendidas e a distribuição geográfica dos resultados.

## Ferramentas Utilizadas

- Microsoft Power BI Desktop
- Microsoft Excel
- GitHub
- Base de dados Financial Sample

## Páginas do Relatório

### Página 1 – Faturamento e Indicadores

Apresenta os principais indicadores comerciais:

- Faturamento total por país
- Faturamento total: 118,73 milhões
- Lucro total: 16,89 milhões
- Unidades vendidas: aproximadamente 1,13 milhão

### Página 2 – Análise de Lucros

Apresenta duas visualizações:

- Lucro total por segmento de mercado
- Lucro total por país

A análise permite identificar os segmentos mais rentáveis e observar resultados negativos, como o prejuízo apresentado pelo segmento Enterprise.

### Página 3 – Análise Geográfica e Segmentos

Página desenvolvida para atender à etapa prática do desafio, contendo:

- Mapa de vendas e unidades vendidas por país
- Mapa de lucro total por país
- Gráfico de pizza com a distribuição do lucro por segmento

**Observação:** O segmento Enterprise apresenta resultado negativo, que não é representado proporcionalmente no gráfico de pizza.

## Principais Resultados

A análise dos dados demonstra que:

- Os Estados Unidos apresentam o maior faturamento entre os países analisados.
- A França apresenta o maior lucro total.
- O segmento Government concentra a maior parcela do lucro positivo.
- O segmento Enterprise apresenta resultado negativo.
